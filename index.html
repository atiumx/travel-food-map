歡迎使用 旅行美食地圖

基本操作
📍 探索地圖 拖動地圖、雙指 zoom，點 marker 即見店資料。 上拉底部面板可看全部地點清單。
🌏 揀地區 左上角下拉可切換：九州、大阪、台北、香港。 未來可加入更多地區。
🔍 篩選 上拉面板點「篩選」，可複選菜系、價位、標籤。 揀到的 chip 變紅色，再 tap 取消。
🚶 步行圈 設起點 + 分鐘，地圖畫圈，只看圈內餐廳。 可設多個起點（最多 5 個）。
進階功能
⭐ 收藏 / 心願單 / 已去 點店資料可標 ⭐ 最愛 / ❤️ 心願 / ✅ 已去。 只本機儲存，不同步。
📨 推薦地點 朋友可貼 Google Maps / Tabelog link，owner 審核後加入地圖。 「儲低佬經我審核，批准咗先至 upload」。
📝 寫評論 點店「加評價」可打星 + 留言。 需要邀請碼綁定身份。

💡 隨時 tap sheet 頂 ? 重開呢個教學。

將呢個 app 加入主畫面，可全螢幕用、離線睇地圖、不會誤觸刷新。

iPhone / iPad (Safari)
1️⃣ 用 Safari 開網站 輸入 atiumx.github.io/travel-food-map/ 必須用 Safari，不能用 Chrome / IG 內嵌瀏覽器。
2️⃣ Tap 底部分享掣 Safari 底部（舊 iPad 在頂）中間個「⬆」分享 icon。 如冇看到 toolbar，向下拉頁面取出。
3️⃣ 點「加入主畫面」 在 action sheet 中滑下，點「➕ 加入主畫面」。 中文系統顯示為「加到主畫面」。
4️⃣ 完成 主畫面出現「美食地圖」icon，點一點即開。 以後不用打 URL，離線仍可看地圖。
Android (Chrome)
📱 Chrome 三點 menu 右上角 ⋮ → 「加到主畫面」，接受名稱即可。 某些 Android 顯示為「安裝 app」。

✅ 從主畫面開不會見到 URL bar，並可離線讀取緩存內容。

✓ 你已用 standalone 模式開緊，無需再加。

訪客模式只可瀏覽。輸入邀請碼可解鎖：新增地點、寫評論、加照片。
